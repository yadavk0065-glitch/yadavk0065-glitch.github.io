# ReSell – Second-Hand Buying & Selling Website

> **"Give Your Old Things a New Life."**

A clean, beginner-friendly B.Tech CSE (1st Year, 1st Semester) front-end college project inspired by Cashify, built using **only HTML5, CSS3, and Vanilla JavaScript** (no frameworks, no backend, no external database).

## Live Demo
- **Live Website:** https://moonlit-tanuki-7b7a79.netlify.app/

## Features
- **4 Connected Pages:** Home (`index.html`), Buy Products (`buy.html`), Sell Products (`sell.html`), and About Us (`about.html`)
- **27 Pre-Loaded Products across 9 Categories:** Mobiles, Laptops, Electronics, Books, Furniture, Bicycles, Sports, Watches, and Musical Instruments
- **Live Search & Multi-Filtering:** Search by product name, filter by category, filter by condition (`Like New`, `Good`, `Used`), and sort by price (`Low to High` / `High to Low`)
- **Sell Products with LocalStorage:** Full JavaScript form validation, live image upload preview (`FileReader`), and persistence in browser `localStorage`
- **Manage & Delete Listings:** View and delete your own posted products directly from the Sell or Buy page
- **Product Details Modal & Direct WhatsApp Contact:** View full item details and open a pre-filled WhatsApp chat with the seller
- **Responsive Design:** Works smoothly on desktop, tablet, and mobile screens

## How to Run Locally
1. Clone or download this repository.
2. Open the folder in **Visual Studio Code**.
3. Open `index.html` and click **Go Live** (using the **Live Server** extension), or double-click `index.html` to open it in any browser.

## Technologies Used
- **HTML5** – Semantic structure across all 4 pages
- **CSS3** – Flexbox, CSS Grid, CSS variables, media queries, and keyframe animations
- **Vanilla JavaScript** – DOM manipulation, search/filtering/sorting, validation, WhatsApp links, and `localStorage`
